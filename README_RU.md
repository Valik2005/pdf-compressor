# PDF Compressor 2.7 — SmartFit

**Бесплатная программа с открытым исходным кодом для сжатия PDF в Windows 10/11 (64 бита).** Полностью офлайн, интерфейс на русском и английском.

**[Скачать PDF Compressor 2.7.0](https://github.com/Valik2005/pdf-compressor/releases/tag/v2.7.0)**

В разделе Assets скачай `PDF_Compressor_2_7.exe` и запусти. Это **один EXE**, Python устанавливать не нужно. Файл не подписан цифровой подписью, поэтому Windows SmartScreen может вывести предупреждение.

## Возможности

- **SmartFit:** анализ PDF (текст, сканы, смешанные страницы) и подбор осторожных параметров сжатия под заданный размер.
- Уменьшение разрешения изображений только с согласия пользователя и улучшенная обработка повторно используемых изображений.
- Пакетная обработка PDF, прогресс, отмена, сравнение размеров и качества.
- Объединение PDF, извлечение страниц и поворот.
- Светлая и тёмная темы, русский и английский языки, работа без интернета.

Достичь указанного размера возможно не всегда. Проверяй качество итоговых PDF, особенно сканов и мелкого текста.

Код приложения распространяется по **AGPL-3.0-only**. В [релизе 2.7.0](https://github.com/Valik2005/pdf-compressor/releases/tag/v2.7.0) доступны контрольные суммы, соответствующие архивы исходников Qt/PySide6/PyMuPDF/MuPDF и сторонние лицензионные уведомления. Для пересборки одного EXE с заменёнными совместимыми библиотеками Qt см. [инструкцию](docs/LGPL_RELINKING_2_7.md) и [уведомления](docs/THIRD_PARTY_NOTICES_RELEASE_2_7.md).

## Запуск из исходников

Windows, Python 3.11+:

```powershell
python -m pip install -r requirements.txt
python app.pyw
```

Тесты: `python -m pip install -r requirements-dev.txt`, затем `python -m pytest -q`.

См. [инструкцию по сборке](BUILDING.md) и [описание SmartFit](docs/SMARTFIT_2_7.md).
