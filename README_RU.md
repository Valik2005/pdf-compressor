# PDF Compressor 2.6

[English README](README.md)

**PDF-сжиматель и инструменты для страниц**, полностью локальная программа для Windows на Python и PySide6. Интерфейс на **русском и английском**, тёмная и светлая темы.

> Документы обрабатываются на компьютере, без загрузки на сервер.

## Возможности

- Сжатие одного или десятков PDF за раз.
- Четыре режима: до заданного размера, максимальное качество, сбалансированный, максимальное сжатие.
- Сначала оптимизация без потерь, затем при необходимости JPEG-сжатие встроенных изображений.
- Выделяемый текст по возможности сохраняется; изображения могут потерять часть качества.
- Отображение прогресса, отмена операции, статистика размера.
- Сравнение страниц до/после с масштабированием, переключением страниц и поворотом предпросмотра.
- Объединение PDF, разделение/извлечение страниц и поворот документа.
- Выбор папки и шаблона имени, сохранение настроек, выбор языка без перезапуска.
- Исходные PDF не перезаписываются.

**Важно:** указанный размер (например, 1 МБ) — **цель, а не гарантия**. Не каждый PDF можно уменьшить до такого размера без заметной потери качества. Изменение PDF может нарушать цифровые подписи, поэтому программа блокирует часть операций для подписанных документов.

## Скачать EXE без Python

После загрузки проекта на GitHub Windows-сборка автоматически создаёт **`PDF_Compressor_2_6.exe`**. Готовый файл можно скачать в разделе **Actions → Windows EXE and Release → Artifacts**. Для красивой страницы скачивания через **Releases** запусти там же **Run workflow** с версией `v2.6.0`: EXE прикрепится к черновику релиза. После проверки условий лицензирования можно опубликовать релиз.

Подробная инструкция: [EXE_RELEASE_GUIDE_RU.md](EXE_RELEASE_GUIDE_RU.md).

## Установка на Windows

Нужен Python **3.11 или новее** (в том числе 3.14).

1. Нажмите **Code → Download ZIP** на GitHub и распакуйте архив.
2. Запустите **`Установить_и_запустить.bat`**. Скрипт установит необходимые библиотеки и откроет приложение.
3. Для ручного запуска:

   ```bat
   python -m pip install -r requirements.txt
   python app.pyw
   ```

4. Выберите **Русский / English** в верхней части программы. Настройка сохраняется.

Если приложение уже установлено, можно обновить только `app.pyw`. Для запуска без CMD открывайте `app.pyw` напрямую.

## Сборка EXE

Запустите **`Собрать_EXE.bat`**. Скрипт соберёт файл `dist\PDF_Compressor_2_6.exe` через PyInstaller. Готовый Windows EXE необходимо собирать **на Windows**. В репозитории хранится исходный код, а не скомпилированный бинарник.

## Тесты

```bat
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют PDF-движок и перевод. Реальное отображение интерфейса и масштабирование Windows необходимо дополнительно проверять вручную.

Для публикации в свой репозиторий есть скрипт `Publish_to_GitHub.bat` (требуется Git for Windows). См. [инструкцию](GITHUB_UPLOAD_RU.md).

**PyMuPDF распространяется по AGPL-3.0 или коммерческой лицензии**, PySide6 — по LGPL/GPL или коммерческой лицензии. Перед публичной раздачей EXE необходимо проверить обязательства соответствующих лицензий. Подробнее — [DEPENDENCIES_AND_LICENSING.md](DEPENDENCIES_AND_LICENSING.md).

## Примечание

JPEG-сжатие изображений не полностью без потерь. Программа не связана с разработчиками PyMuPDF, Artifex и Qt. Для важных документов сохраняйте резервные копии.
