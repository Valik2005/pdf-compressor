# PDF Compressor 2.7 — SmartFit (предварительная версия)

**Офлайн-сжатие PDF для Windows. Открытый исходный код, русский и английский интерфейс.**

> **Ветка разработки:** здесь находится исходный код предварительной версии 2.7. Предварительный EXE собран и запущен на Windows 11 (08.11.2026), но лицензирование публикации ещё проверяется. Стабильную программу можно скачать из [релиза PDF Compressor 2.6](https://github.com/Valik2005/pdf-compressor/releases/tag/v2.6.0).

## Что добавлено

- SmartFit — определение типа PDF и автоматический осторожный подбор сжатия под указанный размер.
- Уменьшение разрешения изображений только с разрешения пользователя.
- Корректная обработка одного изображения, повторно используемого на нескольких страницах.
- Ограничение размера миниатюр для снижения нагрузки на слабые ПК.
- Понятное сообщение, если достичь заданного размера не удалось.

[Подробнее о SmartFit и ограничениях](docs/SMARTFIT_2_7.md).

## Запуск из исходного кода

Нужен Python 3.11+ на Windows 10/11 (64 бита):

```powershell
python -m pip install -r requirements.txt
python app.pyw
```

Тесты:

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

**Это ещё не публичный стабильный релиз 2.7.** Сборка и запуск EXE на Windows 11 проверены, но окончательная сборка, лицензионные условия и [контрольный список выпуска](docs/RELEASE_CHECKLIST_2_7.md) ещё требуют завершения. См. [BUILDING.md](BUILDING.md) и [черновик уведомлений](docs/THIRD_PARTY_NOTICES_2_7.md).
