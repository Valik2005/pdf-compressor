## PDF Compressor 2.7.0 — Windows

**[⬇ Скачать PDF Compressor 2.7 (EXE)](https://github.com/Valik2005/pdf-compressor/releases/download/v2.7.0/PDF_Compressor_2_7.exe)**

Бесплатная офлайн-программа для Windows 10/11 (64 бит). Один EXE, без установки Python и без передачи PDF в интернет.

### Что нового
- **SmartFit:** автоматический подбор вариантов сжатия под заданный размер PDF, включая текстовые, сканированные и смешанные документы.
- Настраиваемое уменьшение разрешения изображений, более бережная обработка общих изображений.
- Ускорение поиска параметров, улучшение отображения списка файлов.
- Пакетная обработка и отмена, просмотр и сравнение, объединение, извлечение и поворот PDF.
- Русский и английский интерфейс, светлая и тёмная темы.

### Важная информация
Размер, указанный в SmartFit, — цель, не гарантия. Проверяй качество сжатых сканов, печатей и мелкого текста. EXE не подписан цифровой подписью: Windows SmartScreen может отобразить предупреждение.

Приложение распространяется под GNU AGPL-3.0-only. В архиве **Third_Party_Sources_and_Licenses.zip** доступны исходники QtBase, QtSvg, QtImageFormats, PySide6/Shiboken, PyMuPDF и MuPDF, соответствующие исходные контрольные суммы, лицензии и материалы по пересборке одного EXE с совместимыми заменёнными Qt DLL. Архив хранит исходные файлы без изменения их содержимого.
