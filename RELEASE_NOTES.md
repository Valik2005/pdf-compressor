# PDF Compressor 2.6 — Windows

Standalone **64-bit Windows executable**. Does not require separately installed Python or Python packages.

**Download** `PDF_Compressor_2_6.exe` under **Assets** below. Open it to start the application (no CMD window).

Features: Russian / English interface, light and dark themes, batch PDF compression, file-size target and quality presets, page preview and before/after comparison, merging, splitting, and rotation. Processing is local; original PDFs are left unchanged.

The binary is built automatically from this repository using GitHub Actions and PyInstaller on a Windows runner. It is **unsigned**, so Windows SmartScreen may warn about an unfamiliar application. Only run software you trust and can inspect.
