## Features

- Russian and English interface
- Light and dark themes
- Batch PDF compression and target file size
- Before/after PDF preview
- Merge, split and rotate PDF pages
- Local PDF processing without uploading files to a server

The executable is unsigned, so Microsoft SmartScreen may display an unfamiliar-app warning.
